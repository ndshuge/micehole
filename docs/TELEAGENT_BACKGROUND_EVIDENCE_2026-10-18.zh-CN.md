# TeleAgent 后台 GUI 兼容性实测（2026-10-18）

本页是 [Mice Hole 后台优先 GUI](BACKGROUND-GUI-2026-10-18.zh-CN.md) 的单软件实验记录，并不等同于所有 TeleAgent 功能已受支持。

## 不抢焦点实验

- 目标：安装在 Windows 上的 TeleAgent（实验界面出现 v2.7.0）。开始时主窗口最小化。
- 只针对既有窗口进行短暂测试：先保存原始 show state 和 normal placement，将正常位置移动至所有监视器边缘以外，再使用不激活窗口的 Win32 操作恢复。
- 恢复时 TeleAgent **没有成为前台窗口**；实验结束使用无激活最小化并恢复原位置。没有物理鼠标操作、提交任务、发送消息或修改 TeleAgent 设置。
- 对未最小化窗口调用 Win32 PrintWindow 返回成功：1821 × 1213 像素，24 × 16 网格采样有 15 种颜色；核心区域有 5 种颜色。**这只能证明画面不是完全单一颜色，不能保证业务区域实时、内容完整或被遮挡情况下所有 GPU 帧都可捕获。**
- UI Automation 首次抓取只见 9 个 Pane；界面加载完成后识别 110 个节点，其中 53 个 Button、1 个 Edit。自动化应等待 UIA 树就绪，不能从早期空树推出“不支持 UIA”。
- 使用 UI Automation Invoke 调用仅有的 `Minimize` 标题栏按钮，结果窗口正确最小化，前台焦点始终未被 TeleAgent 占用，主桌面不需接管。此项属于 **安全、可逆的真实后台 GUI 操作已通过**。

## 已验证与未验证

| 能力 | 结论 |
| --- | --- |
| 不激活的屏幕外恢复和最小化 | 通过 |
| PrintWindow 返回非全纯色像素 | 通过初检，画面完整度未验 |
| UIA 读取 TeleAgent 元素树 | 通过（需等待加载） |
| UIA Invoke 标题栏最小化按钮 | 通过 |
| TeleAgent 业务按钮后台执行 | **未验** |
| 消息输入、发送、会话切换等 | **未验** |
| 窗口最小化时可靠截图 | **不支持／明确失败** |
| 持续后台运行时游戏 FPS 不受影响 | **未量化** |

## 工程边界

1. 公开版仍默认优先 API/CLI/无头浏览器、原生 Win32 按钮；本实验所用的 UIA Invoke 是受控测试脚本能力，**不表示公开 MCP 接口已经适配 TeleAgent 全部 UIA 控件**。
2. 对于自行绘制的应用，后台图像和 UIA 元素的兼容性必须逐一测试，不应该强行切前台兜底。
3. 正式运行中的 MCP 进程必须重启才能加载更新的 ESM 源码，热替换磁盘文件不影响已加载模块。重载可能短暂中断 ChatGPT 连接，需要先备份并确认权限及恢复方案。
4. 不因旧版的最小化窗口返回小尺寸图片就宣称截图成功；应严格区分窗口捕获 API 成功与业务画面质量通过。
