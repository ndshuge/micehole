# MiceHole v3.0.1 · 安装与可靠性更新（2026-10-17）

**这一版的重点不是增加 AI 功能，而是让朋友更容易安装、维护，并在断线时知道先检查什么。**

## 更新了什么？

- **首次安装更容易**：新版 ZIP 增加 `START-HERE.cmd` 与中文分步指南；双击后完成本机初始化和 Doctor 检查。远程高权限仍需本人单独授权。
- **朋友的工作区规范自动初始化**：第一次 Setup 如没有 `AGENTS.md`，会创建一份简短规则；已有文件一律保留，不覆盖。规则强调首次接触陌生软件优先找官方 CLI/API、GUI 兜底，项目只在关键里程碑写 MD。
- **项目记忆更可靠**：延续最近 main 更新的按需续工、检查点去重与临时进程状态不污染 Markdown 的改进。
- **手动更新有明确操作说明**：保留原安装路径、停止个人 Tunnel、备份旧版目录、验证新版本，失败可回滚。Setup 重复运行会复用已经登记的工作区。
- **跨电脑路径更可靠**：少量辅助脚本移除了开发者 E 盘默认路径，改用朋友自己的工作区。
- **网络故障诊断**：提供可选的 `scripts/network-doctor.ps1`，优先检查本地代理端口、HTTPS/OpenAI 基础路径和本地 Tunnel 端口，减少无谓的反复重启。是否流量耗尽仍需在服务商后台确认。

## 不包含什么？

- 不内置机场订阅或某个地区的节点选择，也不会自动修改 Clash、DNS 或系统代理。已经使用 Clash/Mihomo 的用户可自行利用其现有 `fallback`。
- 不包含作者私人 Hanako 双桥、个人 CMD、工作区、令牌、机场数据。
- 不增加新的 Agent、MCP 工具数量、账户额度或高权限授权。
- 不承诺长期 MCP 会话无缝切换节点，或所有朋友的远程高权限场景已通过端到端验收。

## 下载安装

GitHub Release： https://github.com/ndshuge/micehole/releases/tag/v3.0.1

下载 Windows ZIP 与同版本 SHA256 校验文件，验证解压包后阅读 ZIP 根目录的 `START-HERE.zh-CN.md`。

**已安装 V3 的用户，请先阅读 `MANUAL-UPDATE.zh-CN.md`，不要直接覆盖旧目录，也不必重新输入个人密钥。**

## 本轮验收

- Windows 下的首次 Setup、重复运行的工作区保留、AGENTS 规则保留；
- 原有 Direct 12 工具与高权限明确授权门控；
- 项目 MD 习惯回归；
- 网络诊断的端口关闭、显式本地代理、HTTP 204/401 基础探测；
- 通过干净源码打包与 ZIP 解压后本机检查（以发布时的实际验收结果为准）。

**仍需要朋友自主验证**：个人 ChatGPT MCP/Tunnel 可用性、GUI 具体软件、跨版本长时间连接、异常重启恢复。工作区规范是指导，不等于每个新会话都会自动读取。
